Plutonium-CGAPI

Self-hosted cloud gaming API server for Plutonium Network. It streams games over WebRTC with session lifecycle management, rate limiting, and queue handling.

Server is running
Endpoints
MethodPathDescription
GET/cloud/v1/configList enabled sites and their API keys
POST/cloud/v1/createSessionStart a new game session (NDJSON stream)
GET/cloud/v1/getQueuePoll queue position for a session
POST/cloud/v1/startGameActivate a session and get WebRTC connection info
POST/cloud/v1/pingSessionKeep a session alive and get quota stats
POST/cloud/v1/quitSessionTerminate a session
GET/cloud/v1/embedWebRTC game embed page
GET/cloud/v1/embed-dataICE servers and signaling WS for an active session
WS/cloud/v1/signal/:uuidWebRTC signaling channel

All session endpoints require Authorization: Bearer <api_key>.
API keys are configured per-site in sites.json.
